# LearnLoop

> Collect tiny adventures.

LearnLoop is a curiosity playground for learning in small, satisfying loops: read a short lesson, answer one good question, and keep the thread moving.

## What is inside

- Short quests across Space, Creativity, and Nature
- Knowledge checks with XP and level progression
- Daily streak tracking based on completed learning moments
- Bonus Missions for noticing the world differently
- Curiosity Forge for turning one spark into three creative directions
- Learning log and unlockable badges
- Local-first progress with no login or API keys

## Run it

```bash
pnpm install
pnpm --filter @workspace/learnloop run dev
```

## Verify it

```bash
pnpm --filter @workspace/learnloop run typecheck
pnpm --filter @workspace/learnloop run build
```

## Built with

React, TypeScript, Vite, Tailwind CSS, Lucide icons, and browser localStorage.
